# 外部因子探针：极简双参数（趋势+量能）能否合并进威科夫

> 来源文章：《量化交易员含泪醒悟！扔掉几百个复杂因子，全程只靠2个参数》(今日头条, 2026-09-21)
> 探针日期：2026-09-24 ｜ 全池 266 只(沪深300可得数据) ｜ 对照 135 V18-ATR

## 一、从文章提炼的因子（只取可量化 + 不冗余）

| 因子 | 文章说法 | 量化表达 | 与威科夫现状 | 判定 |
|---|---|---|---|---|
| **F1** MA20 regime | 空头(20日线向下+价在下方)100%空仓 | MA20斜率↓ 且 close<MA20 → 不交易 | Spring 信号 100% 落在空头区 | ❌ 证伪：把 Spring 全滤光 |
| **F2** 爆量离场 | 急涨后过量爆量=止盈拐点 | 量>3×均量20 且 近10日涨>10% → 离场 | R1 只预警不离场 | 增强 R1 |
| **F3** MA20 硬止损 | 有效跌破20日线=止损 | 收盘连续2根<MA20 → 离场 | 现有 ATR 吊灯 | 备选止损 |
| **F4** 趋势确认 | 多头趋势才低吸 | Spring 后等 MA20 斜率转正才入场 | 把 Spring"低位埋伏"变成"追高" | 冲突 |
| 良性缩量/放量 | 洗盘拐点/启动确认 | ≈ S2 Test / S3 SOS | 已冗余 | 不取 |

**F1 直接证伪**（诊断：全池 333 个 Spring 信号，328 个落在 MA20 空头区，F1 过滤后持仓段=0）。文章的"趋势跟随"哲学与威科夫的"底部陷阱"逻辑是**互斥的两套体系**——Spring 的价值恰恰在趋势还没走好时低位埋伏，任何"等趋势确认"的因子都在摧毁它的 edge。

## 二、全池探针（S1-only 基准 + 文章因子）

| 口径 | 组合总收益 | 最大回撤 | 收益/回撤 | 单票占优率(vs V18) |
|---|---|---|---|---|
| S1-only 基准 | **+29.3%** | 12.0% | **2.45** | 149/266 = 56% |
| +F4 趋势确认 | 2.0% | 8.8% | 0.23 | 205/266 = **77%** |
| +F2 爆量离场 | 21.3% | 12.5% | 1.70 | 144/266 = 54% |
| +F3 MA20止损 | 14.0% | 17.4% | 0.80 | 195/266 = 73% |
| F4+F2 确认+爆量 | 9.7% | 9.4% | 1.03 | 208/266 = 78% |
| V18-ATR 对照 | 17.9% | 12.6% | 1.42 | 基准 |

## 三、判定

**没有任何口径同时满足"占优率≥60% 且 收益>V18对照(17.9%)" → 文章因子不能合并进威科夫。**

关键背离：**占优率过线的三个（F4 77% / F3 73% / F4+F2 78%），组合收益全崩到 2~14%，全输给 V18 对照。**

根因 = 135 项目一贯的"时段错配"：
- F4/F4+F2 靠"晚入场、少交易"把单票排名拉上去（不容易输给 V18），但同时也放弃了 Spring 低位埋伏的 alpha，**绝对收益大幅缩水**。占优率高 ≠ 赚钱多，只是"少做、少输"。
- F3 占优率 73% 但收益 14% < 基准 29% < V18 对照 17.9% 之间，MA20 止损比 ATR 吊灯更早砍了 Spring 的正常波动，回撤反而更大(17.4%)。
- F2 爆量离场占优率还略降(54%)，说明"急涨后爆量"这个离场点在 A 股 Spring 场景下没有稳定增益。

## 四、结论

1. **Spring(S1) 保持原样**（S1-only 仍是最优组合层口径：+29.3%、收益/回撤 2.45、占优 56%）。
2. **文章的 F1/F4（趋势跟随）与威科夫底部逻辑互斥，不采用。**
3. F2 爆量离场、F3 MA20止损 可留作备选，但全池未证明优于现有 ATR 吊灯，**不落地**。
4. 再次印证核心教训：**复杂因子（含文章推崇的"简化后双参数"）都难在结构层外再提 alpha；威科夫的增量只在"Spring 陷阱 + 组合层资金管理"，不在信号侧再叠因子。**
