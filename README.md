# Wyckoff 威科夫量化策略

基于 **威科夫交易法 (Wyckoff Method)** 的 A股量化策略研究项目。把"交易区间 TR / Spring / Test / SOS / Upthrust"这套主读盘逻辑量化工化，用全池回测检验其能否相对 135 V18-ATR 产生增量。

> **结论先行（2026-09-24 全池 266 只）**：Spring(S1) 是核心 edge，独立组合层 +30%、收益回撤比 2.47 为正向"卫星策略"候选，但**单票占优率卡在 53~56%（<60% 落地线）**，且并入 135 主配置后为负向。→ 建议**不并入 135，仅作独立卫星策略**。详见 `research/full_pool_report.md`。

## 一、方法论速览

三大定律（量化的出发点）：

| 定律 | 内容 | 量化表达 |
|---|---|---|
| 供需 | 需求>供应→涨；供应>需求→跌 | 量价对比：放量滞涨=供应；缩量下探=供应衰竭 |
| 因果 | 交易区间(TR)的"因"孕育趋势"果"：横有多长竖有多高 | 用区间天数/幅宽量化蓄势强度 |
| 努力vs结果 | 成交量是努力，价格变动是结果；背离预示转折 | 放量但价格不动=吸筹/派发特征 |

### 信号定义（本项目的最小可量化信号集）

| 信号 | 含义 | 触发条件 | 用途 |
|---|---|---|---|
| **S1 Spring** | 底部洗盘陷阱 | 低<TR下界 且 收盘收回区间 且 下穿缩量(≤1.0×20日均量) 且 浅破(不深穿) | **核心买入** |
| **S2 Test** | Spring 后确认 | Spring 后10日内 缩量再探底(不深破Spring低点) | 加仓/过滤 |
| **S3 SOS** | 强势突破 | 放量(≥1.5×均量) 收上TR上界(无近期Spring时) | 替代买入 |
| **R1 Upthrust** | 顶部假突破 | 放量(≥1.5×均量) 突破TR上界 当日收回 | **风控离场预警**(仅做多场景) |

**TR（交易区间）判定**：近 40 日(≥20 天) 高低幅宽 ≤ 25% 且窗口内含 ≥1 根放量恐慌 K线(vol ≥ 1.8×20日均量)。

**出场**：`max(结构性止损, 吊灯止损 最高价−2.5×ATR14)`；Spring 低点×0.99 为结构性硬止损；可选 R1 顶部 Upthrust 触发离场；离场后冷却 20 日。**无未来函数**：TR 窗口截至 i−1 日，入场价 = 次日开盘。

## 二、全池验证结论（沪深300，2023-01→2026-08，组合层 10%×5只）

| 变体 | 组合收益 | 最大回撤 | 收益/回撤比 | 单票占优率 |
|---|---|---|---|---|
| S1+S2+S3 全信号 | +30.6% | 12.4% | **2.47** | 53.4% |
| S1-only | +29.3% | 12.0% | 2.45 | 56.0% |
| S1-only + 浅破≤3% | +29.3% | 12.0% | 2.45 | 55.6% |
| V18-ATR 对照组 | +17.9% | 12.6% | 1.42 | — |
| **V18 + 威科夫S1 融合** | **−5.5%** | 9.8% | −0.56 | 44.4% |

**判定**（沿用 135 项目"全池 ≥60% 单票占优才落地"的方法论）：
1. **独立落地未过线**：Spring 占优 53~56% < 60%，不作独立主配置；但组合层正收益 +30%、收益回撤比 2.47，是合格的**卫星策略**候选。
2. **浅破收紧无增益**（55.6%≈56%）：全池 Spring 多数本就浅破，深度约束无区分度。
3. **并入 135 融合为负向**：威科夫 S1 信号密度高，在"先到先得"名额竞争里抢占 V18 名额，组合层转负。再次印证 135 核心教训——**alpha 在结构层（组合资金管理+止损），不在单一信号层**。

## 四、快速开始

依赖：`pip install -r requirements.txt` + 本机 `hithink-finance` CLI（同花顺行情，需已登录）。

```bash
# 单票看信号 (默认 601728.SH)
python3 demo.py 601728.SH --all

# 主回测: 全池 vs V18-ATR 对照 (组合层)
python3 run_wyckoff_backtest.py            # 全池 300 只 (~8min)
python3 run_wyckoff_backtest.py --top 30   # 快速冒烟

# 步骤①探针: S1-only + 浅破收紧
python3 run_wyckoff_s1_shallow.py --depth 0.03

# 步骤②探针: 并入 135 V18 组合层
python3 run_wyckoff_fusion.py
```

作为库使用：
```python
import wyckoff as W
df = W.get_stock_history('601728.SH')          # 日线 OHLCV
sig = W.detect_wyckoff(df)                      # 信号事件表 (S1/S2/S3/R1)
segs = W.wyckoff_segments(df, use_r1_exit=True) # 持仓段 (单票顺序)
res  = W.portfolio_simulate(segs_map, prices, calendar, 1e6)  # 组合净值
```

## 五、落地建议（当前阶段）

- **不并入 135 主配置**（融合为负向）。
- 若启用威科夫：作为**独立的纯 Spring 卫星策略**分账户运行，与 135 V18 并行、不混合资金。
- 卫星策略预期：组合层 ~+30%/3年、回撤 ~12%、收益回撤比 ~2.5；因 ATR 吊灯止损兑现呈**脉冲式**，需监测 12 个月无兑现则重审参数。
- 任何参数改动仍须全池 ≥60% 单票占优于 V18-ATR 对照组方可落地。
